# Christmas render of the LEDStar

Blender (Cycles) render of the snowflake PCB hanging on a fir tree, seen from the back. Only the white and yellow LEDs glow.

- `LEDStar_christmas_tree_render.png`: final image (1500 x 1000, ~19 min on 6 CPU cores, denoised with OpenCV)
- `LEDStar_christmas_tree_render_raw_noisy.png`: raw Cycles output before denoising
- `LEDStar_christmas.blend`: the scene (textures packed, 900 px / 24 samples preview settings). Open in Blender 4.0+, press Numpad 0, viewport shading Rendered
- `build_scene.py`: generates the whole scene from the KiCad board; `denoise.py`: post-process (needs `opencv-python-headless`)

## Rebuild

```
mkdir -p work && kicad-cli pcb export glb -f --include-tracks --include-pads --include-zones --include-silkscreen --include-soldermask --subst-models -o work/board.glb ../LEDStars.kicad_pcb
```

Download the 2k blend and textures of the Poly Haven "Fir Sapling" into `work/dl_tree/fir_sapling/` (`fir_sapling_2k.blend` plus its `textures/` folder), then:

```
blender -b -P build_scene.py -- 1500 400 work/out.png
```

## Credits

The tree is built from 33 copies of the *Fir Sapling* model by Poly Haven (https://polyhaven.com/a/fir_sapling), licensed CC0. Everything else (lights, baubles, thread, room, glow) is generated by `build_scene.py`. Render notes: the Debian Blender build has no OpenImageDenoise, hence the OpenCV denoise step.
