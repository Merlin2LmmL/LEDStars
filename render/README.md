# Photorealistic renders of the LEDStar

Blender (Cycles) renders of the snowflake PCB hanging on a fir tree, seen from its back.
There are three LED colour sets, each shown from three camera angles:

| Set | LEDs lit |
|---|---|
| `yw` | warm white + yellow |
| `bw` | white + blue |
| `rg` | red + green |

Cameras: `front`, `left` and `right`.

- `gallery/<set>_<camera>.jpg`: final images, 2400 × 1600, 512 samples, denoised with OpenImageDenoise
- `gallery/thumbs/`: small previews used in the main README
- `LEDStar_hanging_physics.blend` ([download from the Releases page](https://github.com/Merlin2LmmL/LEDStars/releases/latest/download/LEDStar_hanging_physics.blend), 82 MB, kept out of git): the scene with all textures packed. Open it in Blender 4.5 or newer and press **Play**:
  the board drops, the string tightens over the twig and the ornament swings until it hangs still (about 10 s).
  The renders use frame 229.
- `scene.py`: builds the whole scene from the KiCad board export

## Physics

The ornament is not posed by hand.

- **Board:** a 6 g rigid body with real gravity.
- **String:** a loop of 18 small rigid links joined by point constraints. It runs through the hang hole and over a real
  woody twig of the tree, which is an invisible cylinder fitted to the twig in the tree mesh.
- **Start:** the board begins 8 mm too high and tilted 20°, with slack string.
- **Settling:** Bullet does the rest, and the board settles plumb with the back side facing the camera.

## Rebuild

Export the board next to `scene.py`:

```
kicad-cli pcb export glb -f --include-tracks --include-pads --include-zones --include-silkscreen --include-soldermask --subst-models -o board.glb ../hardware/LEDStars.kicad_pcb
```

Download the 2k blend and textures of the Poly Haven *Fir Sapling* into `dl_tree/fir_sapling/`
(`fir_sapling_2k.blend` plus its `textures/` folder). Then render one image:

```
DEVICE=HIP CAM=front LEDSET=yw blender -b -P scene.py -- 2400 512 out.png
```

Environment variables:

| Variable | Values |
|---|---|
| `DEVICE` | `CPU` (default), `HIP` (AMD), `OPTIX` or `CUDA` (NVIDIA) |
| `CAM` | `front` (default), `left`, `right` |
| `LEDSET` | `yw` (default), `bw`, `rg` |
| `PHYS_FRAME` | simulation frame that gets rendered (default 229) |
| `SAVE_BLEND` | path: save the scene as a `.blend` instead of rendering |

The arguments after `--` are the width in pixels, the samples and the output file.
Each final image took about 3 minutes on an AMD RX 9070 XT.
